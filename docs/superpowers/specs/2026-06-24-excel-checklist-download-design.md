# Excel 自主檢核表下載設計

## 目標

將目前「列印檢核表」的 HTML 列印輸出，改為下載由使用者提供之原始 Excel 檢核表轉換而成的空白 `.xlsx` 範本。使用者下載後以 Microsoft Excel 開啟並列印。

## 已確認需求

- 原始來源為 `1.報損作業自主檢核表(得知失竊發生後第一步驟先印這張出來勾選).xls`。
- 範本內容、黃色章節列、框線、字型、粗體、欄寬、列高、列印設定及簽核欄均須保留。
- 不從網頁寫入資產報損單 E 表單單號或其他資料。
- 確認欄與簽核欄維持空白，供列印後人工填寫。
- 網頁上的檢核表預覽維持不變。
- 按鈕文字改為「下載 Excel 檢核表」，點擊後下載 `.xlsx`。

## 方案比較

1. **靜態 `.xlsx` 範本下載（採用）**：最少程式碼，能完整保留原始 Excel 格式，符合本表不需帶入資料的需求。
2. 直接下載舊 `.xls`：雖然簡單，但不符合後續以 Open XML 範本處理報表的方向，且舊格式相容性較差。
3. 以 JavaScript 開啟範本並重寫 XML：本表沒有動態欄位，加入此流程只會增加錯誤面與維護成本。

## 檔案配置

```text
index.html
templates/
  報損作業自主檢核表.xlsx
```

原始 `.xls` 保留在專案外的舊檔資料夾，不納入網站部署。網站只部署轉換並驗證完成的 `.xlsx`。

## 操作流程

1. 使用者在「報損自主檢核表」頁面查看現有預覽。
2. 使用者點擊「下載 Excel 檢核表」。
3. 瀏覽器下載 `templates/報損作業自主檢核表.xlsx`。
4. 使用者在 Microsoft Excel 開啟檔案並列印、手動勾選及簽核。

## 錯誤處理

- 下載連結使用同一 GitHub Pages 網站內的相對路徑，不依賴外部服務。
- 若範本不存在，瀏覽器會顯示下載失敗；驗證階段須以實際部署路徑確認 HTTP 200，避免發布缺檔版本。

## 驗證標準

- `.xlsx` 可由 Microsoft Excel 正常開啟，沒有修復警告。
- 與原始 `.xls` 比對後，文字、格式、分頁及列印範圍一致。
- 工作表保持空白，沒有帶入網頁欄位。
- 網頁按鈕顯示「下載 Excel 檢核表」，點擊後成功下載正確檔名。
- 桌面與手機版頁面均可觸發下載。
- 現有檢核表預覽與其他頁面功能不受影響。

## 本次不包含

- Excel XML 動態資料寫入。
- 其他報表範本置換。
- 檢核內容、簽核流程或網頁預覽版面的改版。

後續有需要帶入網頁資料的報表時，再針對該範本以 ZIP/Open XML 層級精確更新指定儲存格，避免使用 SheetJS 重建活頁簿。
