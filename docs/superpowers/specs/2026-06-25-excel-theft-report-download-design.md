# Excel 失竊報表下載設計

## 目標

同事完成送出失竊案件後，網頁以原始 Excel 報表版型產生一份已填資料的 `.xlsx` 供下載，不帶入舊 VBA、密碼、ActiveX 或範例案件資料。

## 活頁簿內容

固定包含：

- 損失及修復費用計算式
- 電線電纜被竊補充資料
- 電纜失竊案登記表

依填寫的失竊材料動態顯示：

- 有線路材料：現場調查表（線路）
- 有接戶線材料：現場調查表（接戶線）
- 有電表／比流器：現場調查表（電表）

同一案件有兩種以上材料時，各類型使用獨立現場調查分頁，不混在同一張表。未填寫的現場調查分頁在輸出中隱藏。

## 資料規則

- 發現時間與發生時間都使用網頁的通報日期及發現失竊時間。
- 分局依分駐所／派出所自動帶入，沿用舊 Excel 的 54 筆對應。
- 金額與積點使用網頁目前同步的價格資料計算後寫入報表。
- 保留原 Excel 的字型、欄寬、列高、框線、合併儲存格、頁面與列印設定。
- 現場圖、警員職稱、蓋章及簽核欄維持空白，供下載後人工處理。

## 下載流程

1. 使用者按「完成送出」。
2. 系統先檢查至少有一項失竊材料，且品項數未超過原版型容量。
3. Firebase 儲存成功後產生並下載 Excel。
4. 畫面顯示「下載 Excel」按鈕，供瀏覽器阻擋或稍後載入完成紀錄時重試。

## 驗收標準

- `.xlsx` 由 Microsoft Excel 開啟時沒有修復警告。
- 不含 VBA、ActiveX、密碼與範例案件資料。
- 同時填寫多種類型時，各自出現在獨立現場調查分頁。
- 未填寫類型的現場調查分頁為隱藏。
- 分局、日期、材料、數量、重量、金額與合計均正確。
- 原始列印版面與簽核頁配置保持不變。
